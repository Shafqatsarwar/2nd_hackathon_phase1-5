# 🚀 TaskOrch — Cloud-Native AI Task Orchestration

**Production-grade distributed task orchestration system** powering 
multi-agent workflows across cloud infrastructure.
## What Is This?

A full-stack, cloud-native task orchestration platform that demonstrates:
- **Multi-agent coordination** using MCP and OpenAI
- **Distributed state** with Dapr, Kafka, Redis
- **Infrastructure-as-code** with Kubernetes & Helm
- **Real-time UI** with Next.js 15 and WebSocket
- **Production patterns**: resilience, observability, error handling

## Tech Stack

- **Frontend**: Next.js 15, Tailwind, Vercel AI SDK
- **Backend**: FastAPI, SQLModel, PostgreSQL
- **Cloud**: Docker, Kubernetes, Helm, Dapr, Kafka
- **AI**: OpenAI GPT-4o, MCP

Welcome to the final frontier of the Panaversity Hackathon II. This project demonstrates a production-grade, cloud-native application transition from a simple CLI tool to a distributed, AI-orchestrated system.

## 🌟 Vision for Judges
This project is not just a "Todo list." it is a **Spec-Driven Development (SDD)** showcase that highlights:
1. **Agentic Orchestration**: Multi-agent systems managing complex workflows (GitHub Issues, PRs, Web Search).
2. **Cloud-Native Architecture**: Built for scale using Docker, Kubernetes, and Helm.
3. **Infrastructure Abstraction**: Leveraging Dapr for state management and pub/sub.
4. **Resilient Communication**: Integrated Kafka for event-driven task updates.
5. **Interactive UI/UX**: Premium Next.js 15 interface with RTL (Urdu) support and real-time voice integration.

## 🏗️ Core Technology Stack
- **Frontend**: Next.js 15 (App Router), Tailwind CSS, Vercel AI SDK.
- **Backend**: FastAPI (Python 3.12), SQLModel, PostreSQL (Neon).
- **AI**: OpenAI GPT-4o, Model Context Protocol (MCP).
- **Cloud/Infra**: Docker, Kubernetes, Helm, Dapr, Kafka.

## 📈 Evolution Phases
- **Phase I-II**: Foundation with Next.js & FastAPI.
- **Phase III**: AI Integration & MCP Tools.
- **Phase IV**: Local Kubernetes & Helm.
- **Phase V**: Advanced Cloud Features (Dapr, Redis, Kafka).
